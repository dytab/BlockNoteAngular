# ⚠️ DEPRECATED – BlockNote Angular Wrapper

> **This project is no longer maintained.** No new features or bug fixes will be released. The npm package `@dytab/ngx-blocknote` has been deprecated.

This project was an Angular implementation of [BlockNote](https://github.com/TypeCellOS/BlockNote). It aimed to provide the same functionality and appearance as the original React project but with the added benefit of being fully integrated into the Angular framework.
